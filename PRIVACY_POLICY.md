# SAPEI Privacy Policy

  Effective date: June 11, 2026

  SAPEI is an enterprise browser security extension used to monitor and enforce organizational AI usage policies on supported AI chat
  applications, including ChatGPT, Gemini, and Claude.

  ## Data We Collect

  SAPEI may collect the following data when configured by an organization:

  - Device and collector metadata, such as hostname, device ID, operating system, browser type, extension version, tenant ID, and collector
  ID.
  - User or workforce identity provided by managed browser policy, such as user ID or user name.
  - AI application usage metadata, such as supported AI tool name, site URL, timestamp, policy name, policy action, and event status.
  - Prompt security evaluation data, such as prompt hash, detection results, redacted prompt output, and policy decision.
  - Sensitive entities detected in prompts, such as personal information, credentials, payment data, or other configured data types.

  SAPEI is designed to redact or block sensitive content according to organizational policy. Raw prompts are not stored unless explicitly
  enabled by the organization’s policy.

  ## How We Use Data

  SAPEI uses collected data only to:

  - Apply enterprise AI security policies.
  - Detect, redact, block, or report sensitive data in AI prompts.
  - Provide visibility and audit logs to authorized administrators.
  - Maintain collector registration, heartbeat, and policy synchronization.

  ## Data Sharing

  SAPEI does not sell user data. SAPEI does not use user data for advertising, profiling, or unrelated third-party purposes.

  Data is sent only to the SAPEI backend configured by the organization.

  ## Data Retention

  Data retention is controlled by the organization operating the SAPEI backend. Administrators are responsible for configuring retention,
  access control, and deletion policies.

  ## Security

  SAPEI uses browser extension APIs and backend APIs to enforce policy. Organizations should deploy SAPEI over trusted networks using
  authentication, TLS, and managed browser policy.

  ## Contact

  For privacy or security questions, contact the organization administrator responsible for this SAPEI deployment.
